# GlobeChain 参赛视觉初稿

本批包含鲜明未来、复古未来、远未来三种风格。每种风格均有 A4 海报和 80 × 120 cm 展板。

## 文件对应

| 风格 | 文件前缀 |
| --- | --- |
| 鲜明未来 | `future` |
| 复古未来 | `retro` |
| 远未来 | `farfuture` |

- `*-a4.pdf`：210 × 297 mm 单页海报。
- `*-80x120cm.pdf`：800 × 1200 mm 单页展板，按真实物理尺寸建立。
- 同名 `.svg`：可编辑文字、色块、线条及图像位置。
- `*-preview.png`：长边 1800 px 的整页预览。
- `six-designs-contact-sheet.png`：六版对比，上排 A4，下排 80 × 120 cm。
- `poster-validation.json`：物理尺寸、页数与文字提取校验。
- `build-posters.py`：可重复生成 PDF、SVG、预览与校验报告的排版源。
- `assets/`：三幅概念主视觉原图。

## 编辑方法

SVG 文字使用 Microsoft YaHei，可以在支持 SVG 的设计工具中编辑。图像以相对路径引用 `assets/`，移动或交接 SVG 时请保留该目录。PDF 中中文字体已子集嵌入，文字没有做成图片。

要统一修改文案或配色，可编辑 `build-posters.py` 开头的 `COPY`、`STYLES`。A4 和大幅展板分别在 `a4()`、`large()` 中排版；大幅版本采用独立分栏，没有直接放大 A4。

## 当前使用范围

本批定位为设计初稿，适合选择风格、调整文案与确认版式。原始概念图为 1024 × 1536 px；在大幅版的 420 mm 图宽下约为 62 dpi，尚不能称为 300 dpi 印刷定稿。大字、说明文字、线条和色块均为矢量。

制作实物前应按印厂要求确认出血、色彩打样、材质及最终成品尺寸，并准备适合大幅输出的高分辨率主视觉。本批 PDF 未添加出血和裁切标记，按 RGB 设计。

页面已注明主视觉为概念示意，代表性路线不代表唯一真实路线。没有加入未经核实的覆盖数字、二维码、公开网址或 AI 产品能力。产品文案只表达商品拆解、代表性分工、官方贸易统计及来源核验。

本轮已检查六版整页拼板：文字没有越界、截断或与视觉主体重叠。自动校验确认六份 PDF 均为一页、物理尺寸正确且关键中文可以提取。
