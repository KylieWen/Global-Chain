## 一、本批策略（简短）

**定位**：面向公众、学生、记者和外贸/采购调研者，沿一件熟悉商品看懂部件—材料—制造—国家—贸易连线及其出处。

**语气原则**

1. 平实指路：常驻文字只回答「现在看什么、下一步去哪」；动词＋对象写按钮，营销对仗和氛围旁白做减法。
2. 缺失就是缺失：保留「未知 / 未披露 / 待核验 / 估算」等可辨识状态，不补零、不写成一笔带过的空态；同一条状态声明全站只留一处。
3. 状态与来源交给控件和折叠区：口径、方法、版本进「数据说明 / 来源与版本」；控件能表达的不再写句子。

**词表固定叫法**：商品、部件与材料条目、代表性路线、官方贸易统计、材料贸易观察、国家账本、来源与版本；事实状态沿用已观测 / 估算 / 未知 / 未披露 / 无效。

## 二、冻结决策落实情况

1. 首页 h1「一件商品，一个相连的世界。」保留为全站唯一品牌句；眉题与氛围副标题删除，长旁白缩成功能指路。
2. 无人机与通用拆解台统一「展开部件 / 复原部件 / 展开程度」，暂停仍是动作；去掉「程序化」等实现词；顶部真实指标（部件节点 / 一级模块 / 二级部件 / 证据缺口 / 期间）原样保留。
3. 主导航标准入口二级 copy 整列减法；「五类商品」事实漂移随描述删除消除，不硬写商品总数。
4. 页面与图层统一「代表性路线」，首次在地图数据说明保留一处白话解释；「官方贸易统计」名称不变。
5. 卡片计数只留一行；无人机详情内部节点 / 连接计数为 0 时不显示；真实 16 / 3 / 12 与缺口指标不动。
