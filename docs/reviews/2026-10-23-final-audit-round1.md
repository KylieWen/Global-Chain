# Global Chain 展示前独立审查：第一轮

审查日期：2026-10-23（Asia/Singapore）。目标是次日现场展示前的两轮总体优化与收口。第一轮以当前源码、已有验收证据及独立评审实施矩阵为依据；审查开始时本机 3000 端口没有可用预览，因此没有把源码推断写成新的浏览器通过记录。当前公网旧应用为 `6fe4a31`，新角色与本轮改动尚待统一构建、候选验证及发布。

## 展示边界与验收重点

- 多身份选择应改变浏览入口、内容重点与默认路径。身份选择本身不等于账号登录、企业认证或管理员权限；第一版不能暗示企业已经能提交、审核或发布资料。
- 当前深度企业与产业环节目录主要是空调与制冷案例。供应链参与者入口应明确案例范围，不能因五商品地图都存在，就暗示五商品均有同等深度企业目录。
- 世界地图、中国地图、商品、产业与国家账本已有公开验收记录；原始记录不是对正在编辑的新版本的通过证明。新构建必须复查角色切换、菜单、历史上下文和相邻城市点击。
- 来源、年份、未知值和代表性连接边界在所查代码中保持独立，没有发现需要为现场效果而填造数据的理由。本轮不扩充尚无来源的双边伙伴或法规。
- 仍为 IP/HTTP；免费短链接只改善分享入口，不代表站点已配置 HTTPS。明日展示入口以实际验证可达的直接地址为准。

## 第二轮清单

1. 新访客进入首页，选择并切换各身份；刷新、返回、直接地图入口均可继续，窄屏菜单可操作。
2. 手机历史 `globe-chain-smartphone-2026.2`：来源页下载、指南快捷任务、摘要卡、表单提交、空结果返回均保留该版本；导出内容与页面一致。
3. 普通指南页切换空调等商品，以及无效版本回退后切换商品，均显示对应商品结果。
4. 键盘进入商品树“下一步”后焦点落到目标内容；悬停解释与问号触控目标不挤压窄屏内容。
5. 本轮主流程浏览器无页面异常，桌面与 390px 无横向溢出；服务器候选验证后再切换并复验公网。

本报告没有认定全部长期数据补充或账户后台已经完成；不覆盖用户物料和其它聊天未提交内容。
