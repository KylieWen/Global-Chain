# GlobeChain 参赛说明（可直接粘贴）

## 一句话介绍

GlobeChain 是一个面向跨境采购和外贸调研人员的进出口贸易信息查询与指南针网站：用户先选择商品、国家/地区和进口/出口方向，获得关税核验、手续、文件清单和官方入口，再沿商品供应链、国家账本和来源证据补充背景。

## 现实问题

一部手机看似来自一个品牌，实际连接了矿产、材料、芯片、封装设备、制造国家和消费市场。现有信息往往分散在海关数据库、企业资料和产业报告中，普通用户看不懂，研究者也需要反复手工拼接；更麻烦的是，代表性产业路线很容易被误读成某台具体手机的唯一真实路线。

## 解决方案

GlobeChain 的主入口是“商品 + 国家/地区 + 方向”的贸易指南，整理关税核验项、手续、文件、办理步骤和官方门户。供应链、国家贸易账本、材料贸易和制造工艺作为背景研究模块与指南互相链接，但不构成交易撮合、报价或订单系统。

## 当前可运行 Demo

- 商品总览：`/products/generic-smartphone`
- 供应链路径：`/products/generic-smartphone/supply-chain`
- 半导体封装工艺：`/products/generic-smartphone/processes/process-chain-semiconductor-packaging`
- 国家账本：`/countries` 与国家详情页
- 世界地图：`/map`
- 3 分钟引导：`/demo`
- 进出口指南：`/trade-guide`

## 创新点

1. 把“商品 + 国家 + 方向”的进出口查询清单与商品背景放进同一套可追溯维度。
2. 保留供应链、工艺、设备、材料和国家账本作为政策查询的背景解释层。
3. 对官方资料、人工整理、unknown 和真实 0 做明确区分；未知税率显示“待核验”。
4. 每个发布版本不可变、可审计、可回滚，运行时不依赖外部 API。

## 可信边界

平台展示的是公开统计、企业能力资料和人工整理的代表性路线。海关金额不等于利润、成本或手机价格；材料贸易不证明材料进入某部手机；厂商能力不证明向指定客户供货；未知数据不会被填成 0。

## 后续计划

继续补齐封装材料与设备厂商证据、更多组件路线和更多国家年度数据；在证据达到可复核标准后，再扩展汽车、光伏板等商品，不改变核心数据结构。
