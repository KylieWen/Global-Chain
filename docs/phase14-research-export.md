# 第 14 阶段：带 provenance 的研究快照导出

## 目标

把当前商品的 published 数据、路线内容与证据边界作为一个确定性的只读 JSON 快照导出，
用于离线核验、版本比较和后续数据工具消费。导出不调用外部 API，不推断缺失事实，也不
改变路线、观察或证据缺口的状态。

## 导出入口

```text
GET /api/products/{productId}/research-export
```

来源与版本页面提供下载链接。响应使用附件文件名，并通过响应头同时暴露数据集版本、
内容版本和基于完整响应内容计算的 ETag。相同 published 输入应产生相同 JSON 与 ETag。

## 内容

- 商品、国家/地区、生产阶段和分类映射；
- 代表性供应链节点、边和生产活动；
- 商品贸易、宏观指标和材料贸易观察；
- 来源、逐条 evidence、证据缺口和缺失数据说明；
- 数据集版本、内容版本、适用期间、记录计数和解释规则。

导出保留原始 `unknown`、`withheld`、`estimated`、`null` 和真实零值语义。材料双边观察
仍不等于手机用途，路线边仍不因导出而从 `representative` 升级。

## 架构边界

导出由 domain query 组装，Web API 只负责序列化、缓存校验和下载响应。页面不直接读取
fixture 文件；未来切换到数据库 adapter 时，导出调用方与格式边界可以保持不变。
