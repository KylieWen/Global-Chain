# GlobeChain 完整产品迭代清单

建立日期：2026-10-21。以完整可用产品为目标，按依赖拆成可验证批次；下列顺序是工程依赖，不是把功能降格为演示页。

## 1. 跨模块与覆盖语义（当前）

- [x] 多商品发布、校验、回滚和历史版本能保留其他商品。
- [x] 商品拆解、组件入口和路线筛选对“有路线/仅类别说明”使用一致行为。
- [x] 商品与组件进入地图时保留商品、组件、版本和期间上下文。
- [x] 地图明确区分代表性供应链与官方贸易统计；两种关系不混画成同一事实。
- [x] 地图年份真正过滤数据；来源记录可就地核验；国家无某类数据时有明确解释。
- [x] 版本页面按真实商品显示，不硬编码手机。
- [ ] 修复组件切换官方贸易后缺少回到成品统计的明确入口；评估接入材料统计。

验收：用户可从商品任意组件开始，理解当前覆盖，进入相应路线/地图/账本/来源并继续探索；没有伪装成功的空链接，不把 unknown 变成 0。

## 2. 先完善手机，再正式扩品

- [ ] 逐项盘点手机无/待查询/待录入字段，区分可查证资料、模型断链与真正缺公开证据的记录。
- [ ] 先补手机组件、材料和工艺的上下游，支持多个有依据的代表分支；不人为指定唯一解或伪造权重。
- [ ] 第二批候选优先调研电动自行车、棉质衣物、大豆食用油等中国常见商品；用户已明确咖啡不优先。
- [ ] 新增数据与内容配置；记录提取时间、转换步骤、验证结果和新发布版本。
- [ ] 原始快照不可变；用可重跑构建器生成候选；通过检查后创建新 release。
- [ ] 新商品复用商品拆解、路线、地图、国家账本、研究导出与来源页面。
- [ ] 视真实资料完成度扩独立电池或材料入口；不以组件数量冒充成品覆盖数。

验收：先让手机已承诺的探索内容更加完整，再新增可独立探索的正式商品；关键事实与关系可追溯，不能把猜测填入空字段。

- [ ] 商品、国家、期间和版本上下文连续；旧版本请求不会静默伪装为当前版本。
- [x] 首批代码release verify、typecheck、lint、单元/契约测试、构建全部完成（146通过、1环境跳过）。
- [ ] 实际浏览器核验核心路径，保留截图与明确结果；断网环境可运行本地已发布内容。
- [ ] 确定观众访问方式；若需要公网部署，先准备具体可审核发布方案再按用户授权执行。
