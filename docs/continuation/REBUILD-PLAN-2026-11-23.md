# GlobeChain 体验层重构方案（2026-11-23）

## 已确认的前提

- 用户确认方案 A：数据、领域查询、测试、不可变 release、发布体系全部保留；只重做前端体验层（视觉、交互、叙事结构）。
- 现有公开站与 Qoder 参赛版在重构期间冻结不动；切换公开站需用户明确确认，旧版保留回退。
- 不新增 AI/LLM、不新增数据库、不硬编码商品/国家/数字；`unknown`、来源、`method`、`datasetVersion` 的呈现规则不变。
- 沿用已确认交互需求：物品多选、颜色区分、箭头方向、线宽优先金额、可拖时间轴。

## 视觉方向（用户已确认，含 11-23 追加需求）

「深色地图集」：暗底全幅地图为绝对主角，细线国界、低饱和底色；强调色只留一个（品牌/交互），物品颜色只用于流向上；大字号中文标题 + 等宽数字呈现年份与金额；卡片与面板去边框化，用留白和层级代替分割线。目标参照是数据新闻作品（如 FT/NYT 交互专题）的质感，而不是后台管理系统。

**用户追加（2026-11-23）**：
1. **主题可自定义**：至少深色/浅色两种模式，深色为默认；设计 tokens 全部可序列化为主题配置，用户选择本地持久化。地图与流向样式参数同样配置化，为后续用户协作优化（分享主题/调参方案）留接口；不引入账号系统。
2. **流向参考 NEXUS**（抖音 aterrimus，https://www.iesdouyin.com/share/video/7705833292104305954）：流向渲染为细密粒子流汇成的光束，节点处汇聚/发光/散开；提供「调节流动」参数抽屉（粒子量、速度、宽度等）。金额→粒子流密度与束宽，物品色→流光着色；尊重减少动态偏好，低端设备回退静态弧线。**粒子流是平台主卖点（用户 11-23 强调），作为专项打磨，不是附属动效；渲染模式可切换：粒子流 / 经典箭头并存，用户可选，选择持久化。**
3. **商品选择参考 DeepSeek 拆解热梗**：实物 3D 模型逐级爆炸图，爆炸层级固定为**整机 → 模块 → 装配体 → 零件 → 材料**五级，点部件即选中上下游物品，与地图联动。五商品当前无 3D 模型资产，先用手机做样板（部件数据最完整），其余商品在模型就绪前用等距分层图兜底；爆炸层级与可选部件全部由既有拆解数据驱动，不写死；某商品数据不足五级时按实际层级渲染，缺层不虚构，补层级属后续内容工作。

首页新叙事：首屏即一张可操作的世界地图（默认一件商品的示例流向），一句主张文案；一条固定的三步路径条「拆解 → 路线 → 账本」贯穿全站，当前所处步骤可见；五个商品作为“故事入口”而非目录列表。

## 批次划分

### 批次 0 · 基线与保障
- 拉 `rebuild/experience-2026-11` 分支；跑全量测试留基线（最近记录 303 通过 1 跳过）。
- 确认 `node scripts/build-qoder-preview.mjs` 参赛静态包流程不受影响。
- 验收：基线绿；公开站未动。

### 批次 1 · 视觉系统 + 双主题 + 首页 + 全站外壳
- 改动面：设计 tokens（色板/字体/间距/动效时长，可序列化主题配置）、深色/浅色主题切换与本地持久化、`SiteShell` 与全局样式、`apps/web/app/page.tsx` 新首页、三步路径导航组件。
- 不动：任何数据文件、查询层、其余页面逻辑（旧页面在新外壳下保持可用）。
- 验收：1440 与 390 截图用户过目，深浅两主题均检查；旧页面无样式崩坏；构建+测试绿。

### 批次 2 · 世界地图交互重做（NEXUS 式流向，主卖点专项）
- 改动面：`apps/web/app/map/page.tsx` 及地图组件——粒子流光束（密度/束宽随金额，物品色着色，节点汇聚发光）、**渲染模式切换（粒子流/经典箭头）并持久化**、「调节流动」参数抽屉、悬停与选中反馈、时间轴播放与拖动、多选物品面板重设计、连线详情改抽屉；深浅主题下均可用，减少动态偏好与低端设备回退静态弧线。
- 主卖点打磨清单：粒子流的汇聚/散开手感、发光与拖尾、数量级差异的可读性（大额不糊屏、小额看得见）、多物品同屏时的层次、60fps 性能预算与粒子数自适应、调参方案可导出/分享（序列化配置，沿用主题配置思路）。
- 复用：`selectTradeFlows` 等现有查询与 URL 状态；不新增商品专属分支。
- 验收：大豆油三色叠加、手机 2023–2025 时间轴拖动、两种渲染模式切换与刷新恢复；390 触屏可完整操作。

### 批次 3 · 拆解 / 供应链 / 账本统一体验 + 3D 爆炸图样板
- 改动面：`products/[productId]` 下拆解、supply-chain、ledger 等页面：跨页转场携带出发状态、来源与数据状态的新呈现；商品选择/拆解入口改 3D 逐级爆炸图，点部件选中上下游并联动地图。
- 3D 实施：先做手机样板。**优先程序化建模**（Three.js/React Three Fiber 用参数化部件直接生成通用商品模型），参考用户提供的抖音图文《给 DeepSeek 派了一个任务 它自己把大疆 Mini 5 Pro 拆了》（https://v.douyin.com/rdOqWNpIxNw/）——纯代码生成无人机拆解交互，正好匹配我们“不对应品牌型号的通用商品”定位，不被外部模型资产卡进度；glTF 精模作为后续可选增强。爆炸层级为整机→模块→装配体→零件→材料五级，层级与部件全部数据驱动，数据不足五级时按实际层级渲染、不虚构；其余四商品在模型就绪前用等距分层图兜底。
- 验收：从首页示例出发，五步主线（选商品→拆解→路线→账本→回地图）无需浏览器后退即可走通；手机爆炸图点选电池可进入锂的供应链。

### 批次 4 · 中国地图、移动端收尾与发布
- 改动面：`map/china` 视觉对齐、移动端全页面走查、性能（首屏体积、地图渲染）。
- 验收：全量测试 + 五商品桌面/触屏回归 + 公网候选验收后，经用户确认再切换公开站；参赛静态包同步更新。
