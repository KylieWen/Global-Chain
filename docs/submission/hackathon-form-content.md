# 黑客松提交表单文案

## 作品名称
GlobeChain

## 赛道
大工黑客松 S2 · 奇绩创坛赛道「为现实打个补丁」

## 一句话介绍
GlobeChain 是一个全球商品供应链与贸易数据可视化平台：以智能手机为例，把商品拆解、代表性供应链路线、各国贸易账本和可交互世界地图串起来，看清一件商品如何连接世界；进出口贸易指南是延伸查询方向之一。

## 项目背景
每天使用的手机连接着矿产、材料、芯片、制造国家和消费市场。这些信息散落在海关数据库、产业报告和政策文件里，普通人难以理解，研究者需要手工拼接。

## 解决的问题
把零散资料变成可以逐层探索的拆解树、代表性路线和国家地图；明确区分产业示意与官方统计，避免把某条路线当成单台手机真实物流、把贸易额当成企业利润。

## 核心功能
1. 商品拆解与供应链可视化：从成品点进部件、材料与矿产。首个示范是通用智能手机。
2. 代表性供应链路线：以电池为例看原料、加工、电芯、模组与组装，每节点带来源和证据等级。
3. 国家贸易账本：进出口、差额、官方储备与 HS 851713 商品观察，保留单位、年份、来源和状态。
4. 可交互世界地图：点击国家高亮，查看有明确报告方和伙伴的双边贸易观察。
5. 进出口贸易指南（延伸方向之一）：编码归类、关税核验、手续与文件、官方入口。覆盖美国进口、德国/欧盟进口、中国进出口示范，分管辖区核验。
6. 来源与版本：查看数据依据，导出带出处与版本的研究快照。

## 技术方案
本地不可变快照经 manifest 索引、Zod 校验和深度冻结后进入只读仓储。领域查询将解析后的来源与数据状态交给 Next.js 服务端页面；地图用本地地理数据绘制。发布和回滚切换版本指针，CI 校验数据、类型、测试与构建。当前没有真实数据库或自动化管线，详见 technical-solution.md。

## 数据来源
World Bank WDI（宏观贸易、官方储备）；UN Comtrade（HS 2022 / 851713 及材料观察）；USGS、IEA、JEITA、SIA 与厂商年报（产业角色）；Natural Earth（国家轮廓）；政府官方入口（静态政策指南）。来源支持范围逐条保留，产业角色不自动证明双边供货。

## 创新点
- 严格不确定性语义：unknown ≠ 0；未知、估算、未披露、已观察与真实零值分别表达，税率未收录标待核验。
- 代表性路线与官方统计分开，不冒充真实物流或客户供货。
- 数据不可变、可校验、可回滚，研究快照可复核；运行时不依赖外部 API，依赖安装后断网可演示，无需 API 密钥。

## 应用价值
公众和学生通过日常商品理解全球分工；记者获得可追溯的解释材料；外贸与采购调研者沿商品、国家和官方入口形成后续核验路径。

## 使用说明与评审路径
仓库根目录执行 pnpm install --frozen-lockfile、pnpm run build、pnpm run start，浏览器访问本地 3000 端口。依次打开首页、/map、/products/generic-smartphone、组件供应链、国家账本、来源与版本，最后展示 /trade-guide 延伸查询。/demo 提供分步入口。HTML Deck 和逐页旁白在 docs/submission/deck。

## 可信边界
2023 年公开数据 · 单商品示范版本 · 覆盖有限 · 未收录税率显示待核验。静态政策需按当前日期、原产地、具体规格和官方系统重新核验。贸易额不等于企业利润；代表性路线不等于某批货物的唯一真实路径。没有实时物流、撮合、报价、订单或运行时 AI。
