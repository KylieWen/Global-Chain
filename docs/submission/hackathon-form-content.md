## 作品名称

GlobeChain

## 所属赛道

奇绩创坛赛道（为现实打个补丁）

## 一句话介绍

GlobeChain 是一个面向跨境采购和外贸调研人员的进出口贸易信息查询与指南针网站：用户先选择商品、国家/地区和进口/出口方向，获得关税核验、手续、文件清单和官方入口，再沿商品供应链、国家账本和来源证据补充背景。

## 项目背景

一部手机看似来自一个品牌，实际连接了矿产、材料、芯片、封装设备、制造国家和消费市场。现有信息往往分散在海关数据库、企业资料和产业报告中，普通用户看不懂，研究者也需要反复手工拼接；更麻烦的是，代表性产业路线很容易被误读成某台具体手机的唯一真实路线，海关贸易金额也常被直接等同于企业利润。

跨境采购和外贸调研人员在开展业务前，需要快速确认商品归类、目的地规则、可能的税费核验入口、资料清单和办理顺序，但这些信息分散在不同官方系统和政策文件中，缺乏一个统一、可追溯、不猜测的查询起点。

## 解决的问题

GlobeChain 把"商品 + 国家/地区 + 进口/出口方向"组织成一条可执行的核验路径：

1. **政策查询不猜测**：关税核验项、手续、文件清单和官方入口按管辖区整理；税率或许可未收录时显示"待核验"，不填充默认值。
2. **背景可追溯**：供应链、国家贸易账本、材料贸易和制造工艺作为背景研究模块与指南互相链接，每条事实带来源、版本和数据状态。
3. **事实类型不混淆**：代表性路线、官方贸易统计和政策指南是三类不同证据，分开存储、分开展示，不互相替代。
4. **未知不等于零**：缺失、未披露、无法匹配、估算和真实为零明确区分，前端有不同呈现。

## 核心功能

### 1. 进出口贸易指南（主入口）
- 选择商品、国家/地区和进口/出口方向
- 展示商品编码（HS 2022 / 851713）、关税核验状态、手续与核验顺序、文件清单、官方入口（如美国 CBP）
- 支持美国进口、德国/欧盟进口、中国出口等快捷查询
- 未知税率显示"待核验"，不显示为 0%

### 2. 商品背景与拆解
- 通用智能手机商品总览与拆解树（成品、部件、材料、矿产）
- 商品门类分类与外部分类编码映射

### 3. 代表性供应链路线
- 材料到组装的代表性路线（电池路径：锂、钴、材料加工、电芯、模组、手机组装）
- 国家节点、生产环节、货物名称、方向、来源和证据等级
- 明确标注"代表性路线，不代表某一批货物的唯一真实路线"

### 4. 半导体封装制造工艺
- 线焊/倒装两类代表路线的结构化验证链
- 18 道工序、18 类设备与首批厂商能力记录
- 保留未验证厂商和客户供货关系的证据缺口

### 5. 国家贸易账本
- 按国家和年份展示进口、出口、贸易差额、官方储备（含黄金）
- 智能手机 HS 2022 编码 851713 的世界总计与具体伙伴贸易观察
- 每个指标带单位、口径、来源、数据状态和版本

### 6. 可交互世界地图
- 基于 Natural Earth 1:110m 国家轮廓，d3-geo Equal Earth 等积投影
- 国家整体轮廓可点击高亮，贸易观察以质心节点和连线展示
- 本地静态几何数据，不依赖运行时地图 API 或网络

### 7. 来源、版本与研究快照
- 每条事实带来源、method、datasetVersion、内容版本和数据状态
- 不可变 release 目录、active manifest、历史版本校验与回滚
- 确定性研究快照导出（携带数据集版本、内容版本、来源、证据和缺口）

### 8. 3 分钟引导演示
- `/demo` 页面提供评审推荐路径的分步引导

## 技术方案

### 整体架构
- **模块化单体**：pnpm workspace，单一部署单元，清晰领域边界
- **五层分离**：Web 展示 / 应用与领域逻辑 / 数据处理 / 数据库（当前 fixture 只读）/ 内容配置

### 技术栈
- **前端**：Next.js 15 App Router + React 19 + TypeScript
- **数据契约**：Zod schema，覆盖国家、商品、年份、单位、数值、状态、来源、method、datasetVersion
- **领域层**：只读仓储接口 + 领域查询服务（商品目录、拆解树、供应链故事、节点详情、国家账本、贸易网络、provenance、研究快照）
- **数据层**：fixture 文件加载适配器，深度冻结的 in-memory repository，默认只读 published
- **地图**：d3-geo@3.1.1 Equal Earth 投影 + world-atlas@2.0.2 Natural Earth TopoJSON + topojson-client，纯 SVG 渲染
- **测试**：Vitest，25 个测试文件、115 个测试，覆盖契约、fixture 完整性、loader 状态边界、领域查询、组件覆盖和发布生命周期
- **CI**：GitHub Actions，frozen install、active release 校验、类型检查、lint、测试和构建

### 数据来源
- 宏观商品进出口与官方储备：World Bank WDI
- 智能手机 HS 2022 六位码 851713 贸易观察：UN Comtrade
- 国家地理维度：UN M49
- 矿产与产业角色：USGS Mineral Commodity Summaries、IEA、JEITA/METI、SIA、TSMC/SK hynix/ASML 年报、中国国家统计局
- 国家边界几何：Natural Earth Admin 0 Countries 1:110m（public domain）
- 贸易指南：人工整理的静态政策资料，带来源、复核日期和覆盖状态

### 运行时边界
- 运行时只读取已发布数据和内容，不调用外部 API、AI/LLM 或生成式服务
- 外部数据只在显式的本地快照脚本中抓取，不在 Web 请求期间访问
- 无数据库迁移、无 PostgreSQL 运行时查询、无实时物流

## 创新点

1. **查询与背景统一维度**：把"商品 + 国家 + 方向"的进出口查询清单与商品供应链、国家账本、制造工艺放进同一套可追溯维度，用户可以从政策核验一路追溯到商品背景和来源证据。
2. **背景解释层而非交易平台**：保留供应链、工艺、设备、材料和国家账本作为政策查询的背景解释层，明确不做交易撮合、报价或订单系统，避开成熟平台的竞争领域。
3. **严格的不确定性语义**：对官方资料、人工整理、unknown、withheld、estimated 和真实 0 做明确区分；未知税率显示"待核验"而非 0%；代表性路线不冒充唯一真实路线。
4. **可审计的数据发布**：每个发布版本不可变、可校验、可回滚；研究快照导出携带数据集版本、内容版本、来源、证据和缺口；运行时零外部依赖。
5. **本地静态交互地图**：用 d3-geo Equal Earth 等积投影和 Natural Earth 静态几何实现可交互国家轮廓地图，不依赖运行时地图 API、令牌或网络连接。

## 应用价值

### 对跨境采购人员
- 快速确认商品归类、目的地规则、可能的税费核验入口、资料清单和办理顺序
- 形成采购前的核验清单，减少因信息遗漏导致的合规风险
- 从商品背景理解为什么某项政策、原产地或产品合规要求会出现

### 对外贸调研人员
- 把国家政策、商品背景、供应链角色和贸易统计放在同一条可引用的研究路径中
- 能够回到官方来源核查，每条事实带来源、版本和数据状态
- 研究快照导出支持可复现的分析和引用

### 对学生、教师、记者和公众
- 提供可解释、可引用的全球化生产和贸易结构教学材料
- 理解一件商品如何连接多个国家、材料和生产环节
- 区分官方统计、人工整理内容和示意推断，培养数据素养

### 社会价值
- 降低中小企业和个人开展跨境贸易的信息门槛
- 促进贸易信息的透明化和可追溯性
- 为后续扩展更多商品、国家和政策领域提供可复用的底层模型

## 使用说明

### 环境要求
- Node.js >= 20.9.0
- pnpm 11.19.0（项目声明使用 pnpm，不要改用 npm/yarn/bun）

### 安装与启动
```bash
cd "D:\Global Chain"
pnpm install
pnpm run dev
```

浏览器打开：http://localhost:3000/

### 评审推荐路径（约 3 分钟）
1. 打开 `/`，说明平台面向跨境采购和外贸调研人员
2. 点击"开始进出口查询"，进入 `/trade-guide`
3. 选择"美国 + 进口"，展示商品编码、关税待核验状态、手续、文件清单和 CBP 官方入口
4. 点击"查看商品背景"，进入 `/products/generic-smartphone`
5. 打开 `/products/generic-smartphone/supply-chain`，展示代表性供应链路线
6. 打开 `/map`，展示国家轮廓和已发布贸易观察
7. 回到 `/trade-guide`，展示德国/欧盟和中国的快捷查询入口

### 质量检查
```bash
pnpm run lint
pnpm run typecheck
pnpm run test
pnpm run build
pnpm run data:release:verify
```

## 可信边界声明

GlobeChain 是静态、部分覆盖的研究起点，不是海关预裁定、法律意见、报关代理服务、供应商担保或交易平台。

- 页面中的贸易金额不等于成本、利润或手机价格
- 供应链路线和产业角色不证明特定企业之间存在供货关系
- 材料贸易不证明材料进入某部手机
- 厂商能力不证明向指定客户供货
- 未知数据不会被填成 0
- 税率或许可未收录时显示"待核验"，必须按当前日期、原产地、具体规格和官方系统重新核验
