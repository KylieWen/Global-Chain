一句话定位
用户选择「商品 + 国家/地区 + 进口/出口方向」，获得关税核验、手续、文件清单和官方入口，再沿供应链、国家账本和来源证据补充背景。
问题与背景

一部手机连接矿产、材料、芯片、封装设备、制造国和消费市场，但信息分散在海关数据库、企业资料和产业报告中，普通人看不懂，研究者需反复手工拼接；代表性产业路线常被误读为某台手机的唯一真实路线，海关金额也常被等同于企业利润。跨境采购人员在业务前需要快速确认商品归类、目的地规则、税费核验入口、资料清单和办理顺序，却缺乏统一、可追溯、不猜测的查询起点。

核心功能
  • 进出口贸易指南（主入口）：商品+国家+方向查询，关税核验、手续、文件清单、官方入口；未知税率显示「待核验」
  • 商品背景与拆解：通用智能手机拆解树，成品→部件→材料→矿产
  • 代表性供应链路线：电池路径（锂/钴→材料→电芯→模组→组装），带来源与证据等级
  • 半导体封装工艺：线焊/倒装两类路线，18 道工序、18 类设备与厂商能力记录
  • 国家贸易账本：进出口、贸易差额、官方储备、HS 851713 贸易观察
  • 可交互世界地图：Natural Earth 国家轮廓 + Equal Earth 投影，本地静态 SVG
  • 来源版本与研究快照：不可变 release、可回滚、确定性快照导出

创新点与应用价值

查询与背景统一维度

进出口查询清单与供应链、国家账本、制造工艺放在同一套可追溯维度，从政策核验一路追溯到商品背景和来源证据。

严格的不确定性语义

官方资料、人工整理、unknown、withheld、estimated 和真实 0 明确区分；未知税率显示「待核验」而非 0%。

可审计的数据发布

每个版本不可变、可校验、可回滚；研究快照携带数据集版本、内容版本、来源、证据和缺口；运行时零外部依赖。

应用价值：跨境采购人员快速形成采购前核验清单；外贸调研人员获得可引用、可追溯的研究路径；学生、教师、记者和公众获得可解释的全球化生产与贸易教学材料。

可信边界：GlobeChain 是静态、部分覆盖的研究起点，不是海关预裁定、法律意见、报关代理服务、供应商担保或交易平台。贸易金额不等于成本/利润/手机价格；供应链路线不证明特定企业供货关系；材料贸易不证明材料进入某部手机；未知数据不填为 0；税率须按当前日期、原产地和官方系统重新核验。
