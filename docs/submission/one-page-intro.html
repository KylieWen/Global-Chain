GlobeChain

进出口贸易信息查询与指南针 · 面向跨境采购与外贸调研
大工黑客松 S2 · 奇绩创坛赛道「为现实打个补丁」· 2026-08
一句话定位
查进出口手续不瞎猜：选好商品、国家和方向，一次看清关税怎么查、要办哪些手续、准备哪些文件、去哪个官方网站核验；再顺手看懂这件商品是怎么做出来的。
问题与背景

你手里的手机，锂可能来自澳大利亚、钴来自刚果、芯片在台湾制造、最后在中国组装。想搞清楚这些事，得在海关数据库、产业报告、政府政策文件之间来回翻，做跨境采购和外贸调研的人尤其头疼。更麻烦的是，「代表性产业路线」常被当成某台手机的唯一真实路线，「海关贸易额」也常被当成企业利润。我们缺的不是更多数据，而是一个把这些信息整理好、讲清楚、不瞎猜的查询起点。

核心功能
  • 进出口贸易指南（主入口）：选商品+国家+方向，得到商品编码、关税核验入口、手续顺序、文件清单和官方网址；未收录的税率明确标「待核验」，不瞎填
  • 商品拆解与供应链背景：以智能手机为例，展示从成品到部件、材料、矿产的拆解，点进电池可看到原料来源国和加工环节
  • 代表性供应链路线：锂/钴→材料→电芯→模组→组装的代表路线，每个节点带来源和证据等级，并明确标注「非唯一真实路线」
  • 半导体封装工艺：线焊/倒装两类主流封装方式，18 道工序、18 类设备与厂商能力记录，已验证和未验证分开标注
  • 国家贸易账本：各参与国的进出口、贸易差额、官方储备，以及智能手机 HS 851713 的具体贸易观察，每个数字带来源
  • 可交互世界地图：国家轮廓可点击、可缩放，连线只展示有数据支撑的双边贸易；本地渲染，断网也能演示
  • 来源与版本：每条信息带来源、复核日期和版本；可一键导出研究快照，写报告引用放心
技术方案
现代 Web 前端 数据本地处理与发布 运行时不调用外部 API 数据可追溯可回滚 自动化测试与持续集成

数据来源包括世界银行 WDI、联合国 Comtrade、美国地质调查局 USGS、国际能源署 IEA、日本 JEITA、半导体行业协会 SIA 及主要厂商公开年报；贸易指南为人工整理的静态政策资料，每条标来源和复核时间。断网可演示，无 API 密钥、无使用成本。

创新点与应用价值

查询与背景放在一起

以前查关税要跑海关网站、看产业背景要翻报告、查贸易数据要下数据库；现在同一网站、同一套维度，查完手续顺手看懂商品全球生产脉络。

明确说「我不知道」

未知、未收录、估算、保密、真实为零明确区分；税率没收录就显示「待核验」，路线不确定就标「代表性路线」，不拿表面「完整」误导用户。

每条信息能回到来源

不是笼统标「数据来源：互联网」，而是每条事实带具体机构、获取时间、数据版本；数据版本不可变、可回滚，引用和复核都放心。

应用价值：跨境采购人员快速形成核验清单、减少漏文件风险；外贸调研人员获得可引用可追溯的研究路径；学生、教师、记者和公众获得看得懂的全球化生产与贸易讲解。

可信边界：GlobeChain 是静态、部分覆盖的研究起点，不是海关预裁定、法律意见、报关代理服务或交易平台。贸易金额不等于成本、利润或手机价格；供应链路线不证明特定企业供货关系；材料贸易不证明材料进入某部手机；未知数据不填为 0；税率须按当前日期、原产地和官方系统重新核验。
