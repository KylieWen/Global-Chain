# GlobeChain 结项验收与演示手册

## 结项定义

当前版本以“可运行、可解释、可复核的进出口贸易信息查询 Demo”为结项范围。核心入口是“商品 + 国家/地区 + 进口/出口方向”的贸易指南；供应链、国家账本、材料观察、制造工艺和世界地图作为背景研究模块保留。

本版本不再扩展交易撮合、报价、订单、实时物流、数据库运行时查询、AI/LLM 或第二个商品。

## 评审推荐路径（约 3 分钟）

1. 打开 `/`，说明平台面向跨境采购和外贸调研人员。
2. 点击“开始进出口查询”，进入 `/trade-guide`。
3. 选择“美国 + 进口”，展示：
   - 商品编码 HS 2022 / 851713
   - 关税待核验状态
   - 手续与核验顺序
   - 文件清单
   - CBP 官方入口
4. 点击“查看商品背景”，进入 `/products/generic-smartphone`，说明贸易指南如何连接供应链背景。
5. 打开 `/products/generic-smartphone/supply-chain`，展示材料、部件、组装和消费市场的代表性路线，并强调它不是某台手机的唯一真实路线。
6. 打开 `/map`，展示国家整体轮廓和已发布观察，说明地图是研究背景而非实时物流地图。
7. 回到 `/trade-guide`，展示德国/欧盟和中国的快捷查询入口，说明不同管辖区需要分别核验。

## 本次结项已验收

- Web 应用可从仓库根目录启动。
- Published release 为不可变本地快照，当前版本：`globe-chain-smartphone-2023.16`。
- 贸易指南由数据契约和领域查询层驱动，页面不硬编码税率或政策结论。
- unknown、estimated、withheld 和真实 0 保持不同语义。
- 每组指南保留来源、官方入口、复核日期、数据集版本和内容版本。
- 首页、贸易指南、商品页、供应链页、国家账本和世界地图均有可访问路径。
- `data/samples` 未作为 published 数据修改。

## 最终质量门槛

从仓库根目录执行：

```bash
pnpm install
pnpm run lint
pnpm run typecheck
pnpm run test
pnpm run build
pnpm run data:release:verify
```

结项时应记录命令输出、当前 Git 提交哈希和 active release。不要在演示前运行会抓取外部数据的 `data:rebuild:smartphone`，以免改变演示版本。

## 对外说明

GlobeChain 是静态、部分覆盖的研究起点，不是海关预裁定、法律意见、报关代理服务、供应商担保或交易平台。页面中的贸易金额不等于成本、利润或手机价格；供应链路线和产业角色也不证明特定企业之间存在供货关系。

## 结项后的维护顺序

1. 先收集 5—10 名跨境采购/外贸调研用户的真实反馈。
2. 优先补齐一个具体高频任务（例如手机电芯进口或封装设备采购），而不是同时扩展大量国家。
3. 每次数据更新都生成新的 release，保留旧版本和来源快照。
4. 只有当第一个任务被真实用户验证后，再扩展更多商品或政策国家。
