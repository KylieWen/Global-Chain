# 粒子流编码实验（2026-11-27 批次 6）

## 目的

地图上现有的粒子流编码（数量 + 尾迹 + 方向配色）不能让人一眼读出金额差异，用户要求先脱离地图，单独用直线形态做十余版对照。

## 做法

- 新页 `/lab/particles`（`apps/web/app/lab/particles/page.tsx` + `apps/web/components/particle-lab.tsx`），不读任何业务数据，纯 Canvas2D 视觉研究；页面标 `robots: noindex`。
- 每个变体一行、三档金额（100 亿 / 10 亿 / 1 亿），除该变体自身的通道外其余条件完全相同；左上角标注编号、名称与一句话说明。
- 变体清单：A 基准 / B 数量线性 / C 数量平方 / D 尺寸 / E 速度 / F 尾迹 / G 细丝束条数 / H 亮度 / I 数量+尾迹 / J 数量+尺寸 / K 离散五档 / L 箭头粒子 / M 脉冲串 / N 束宽+数量。
- 提供暂停与速度滑杆，便于观察速度类变体（E）的动态效果。

## 已知取舍

- 速度编码（E）在静态截图里不可读，只有在动起来时成立。
- 亮度编码（H）最省性能，但弱流在深色底上容易糊掉。
- 数量平方（C）能拉开差距，但 1 亿档几乎不可见。
