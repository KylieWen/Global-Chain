# 整站一致性与手机首屏（批次 2）

日期：2026-11-26
范围：只修三处影响真实使用的问题——地图图例与手势提示互相压字、手机首页 hero 控件压在 CTA 行、手机端首页地图只剩一截裁切。不改数据、不改路由、不新增商品。

## 1. 地图：图例与手势提示重叠

- 现象：1440 下 `.atlas-below-map`（图例 + 「展开供应链 →」）与 `.atlas-map-caption`（「粒子沿货物流向移动 · 双指缩放与移动」）都钉在右下角，提示文字被图例面板压住，末字「动」从面板右缘露出 6px；读起来像渲染错位。
- 处理：不改文案，只改层叠关系——图例面板 `bottom` 从 0.9rem 抬到 2.5rem，浮在手势提示行上方；提示仍贴底右对齐。两行都完整可见。
- 证据：`output/qa/batch2/map-legend-wide.png`（修复后），修复前同目录 `map-legend.png`。

## 2. 手机首页：hero 控件压在 CTA 行

- 现象：390 下「展开其余 12 条流向」按钮（bottom 9.5rem）和「+ / − / 复位」缩放组（bottom 6.5rem）正好落在「从世界地图开始 → / 走进中国供应链 ↗」这一行上，「走进中国供应链」被按钮切断；再往下还压到「空调与制冷产业导览 ↗」。
- 处理：≤640 时把两组控件移到产品切换 chip 下方（`top: 10.4rem`），「展开其余」靠左、缩放组靠右，同一行并排；hero 文案与 CTA 行完全让出。
- 证据：`output/qa/batch2/home-noguide-390.png`（修复后）。

## 3. 手机首页：地图只剩一截

- 现象：hero 地图用 `preserveAspectRatio="xMidYMid slice"` 铺满 100dvh，390×844 竖屏下 slice 按高度放大，横向只剩约 31% 的世界宽度，看到的是欧洲/非洲一截，流向从右缘飞出，落点看不到。
- 处理：宽屏（≥900px）保持 slice 全幅；窄屏改为 `xMidYMid meet`，整幅世界等比缩进、居中，手机上一眼能看到中国→美国/欧洲的完整弧线；同时把 `.map-ocean` 填充向上下各外扩 3 个画布高，避免 letterbox 露出色块接缝。
- 窄屏初始视角也从 1.5× 拉近改为 1×（原逻辑会把两端点都推出画面），聚焦端点改为居中而不是 0.56 偏右。
- 证据：`output/qa/batch2/home-noguide-390.png`（窄屏整幅）、`home-noguide-1440.png`（宽屏未变）。

## 已知取舍

- 窄屏 meet 后地图是一条横向色带，视觉冲击弱于全幅裁切，但能完整讲出「一件商品如何连接世界」；这是视觉取向问题，若用户更想要满屏氛围，可改回 slice 并接受画出画外的流向。
- 手机首屏仍从新手引导开始（首访弹层占满一屏），引导关闭后才是上述首页。
- **下一批首要项（本批未动）**：390 世界地图页的浮动工具条（筛选条件 / 粒子流 / 经典箭头 / 记录 / 大图）整块浮在上方，把产品子导航压住，并露出后面另一条被遮住的按钮行；需要单独排查 `map-focus` 的窄屏工具条布局。
