## 必须交付的纵向切片

1. **工作台**：桌面在现有 GlobeChain 导航内形成全屏深青黑工作台；左上产品标识与真实指标，左侧 16 节点模块树，右侧选中部件详情，中央三维舞台，底部播放、全局拆解滑杆、装回复原。不得用营销落地页或静态海报替代。
2. **新几何**：白色/浅灰低趴流线外壳、黑色前传感区域、四条细长外伸机臂、圆柱电机、细双叶桨、前置独立云台和玻璃镜头。以 Y 为上、XZ 为机体平面，避免竖起来的层叠矩形板；允许新建 Extrude/Lathe/曲线圆角几何，不沿用旧方块机身做微调。
3. **舞台**：青蓝轮廓光、冷色雾化、地面圆形刻度与细网格、柔和投影；细引线与小标签不压主体。三维舞台保持母版深青黑，外围面板与现有主题衔接。
4. **交互**：默认 `explosion=0` 装配态，可 orbit；上壳向上、机臂径向、内部模块分层、云台向下/前分离；播放拆解/装回、滑杆、复原、单件点选/高亮/详情可用，镜头阻尼平滑。减少动态不自动播放，WebGL 不可用保留回退。
5. **移动端**：390 使用舞台优先、控制可达、面板简化/折叠的布局，无横向溢出，不照搬桌面三栏导致舞台缩没。

## 验收与停点

- 先验证装配态和爆炸态，再补动效与移动端；每轮真实 Read 截图，最多三轮聚焦迭代，停滞即收束。
- 1440 分别以 A 的 17.005s 装配帧和 4.7s 爆炸帧做左右并排对照，同时保留深浅主题、云台选中与 390 截图。主模型按机体外形、工作台结构、舞台氛围和动效状态亲看，不能只用占高/留白数字宣称复刻成功。
- 沿用现有路由、选中深链、账本/路线入口和数据状态；外观装饰不新增报价 BOM。其他商品与手机 round-7 不回归。
- 跑相关契约、typecheck/lint、受影响渲染回归、生产构建和六快照静态包，不重复无意义全量测试。完成后保存证据、独立提交与 RECOVERY，停在主模型看图；Qoder 403 不探测、不兑换、不冒称参与。
