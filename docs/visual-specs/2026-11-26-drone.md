# 无人机第二阶段：程序化外观与主线验收规格

日期：2026-11-26  
商品：`generic-camera-drone`（航拍无人机）  
阶段边界：本阶段只交付无人机，不启动光伏、锂电或其他新商品。

## A. 数据与叙事前提

- 通用 BOM 只使用已落盘的 DJI Mini 系列官方维修部件快照及 86 条结构化部件行能够支持的事实；通用层级按实际证据呈现，不为凑满「整机→模块→装配体→零件→材料」虚构节点。
- 维修备件 CNY 报价不是制造成本、利润或整机零售价。产地、材质、供应商、产能和工艺没有证据时保持 unknown / 待核验。
- 本地没有 HS 8806 的真实贸易观测。分类字典不能冒充贸易记录；世界地图、材料贸易、代表性路线与国家账本使用现有空态，不生成无来源国家连线或 0 金额。
- 页面叙事聚焦「一架无人机如何连接世界」：从核心板、视觉组件、云台和机臂认识结构，再沿有证据的材料与贸易记录继续追踪；缺失入口必须诚实可达。

## B. 程序化外观

- 几何、节点和深度来自真实 BOM 与 `content/exploded-appearance.json`；核心组件不得出现 `generic-camera-drone` 专用分支。可增加可复用的程序化部件角色，缺配置沿用通用兜底。
- 默认态应读出中央机身、四个折叠机臂、对应桨叶组和前置/下置云台相机。折叠不是展开四轴机架；桨叶采用简洁双叶程序化几何，不导入外部模型。
- 默认透视下四组机臂/桨叶尽量可辨；若投影遮挡，默认态至少三组清楚可辨，轨道旋转后第四组可见。云台镜头不得完全陷入机身。
- 默认爆炸度与取景占高解耦，由配置决定；层距只表达已有 BOM 层级，不把深度差伪装成供应关系。
- 材质未证实的零件使用中性结构色，不用颜色暗示已核实材料。
- FPV-Viewver 仅用于核对九部件分组、爆炸/装回与懒加载规律；许可证未确认前不得复制其代码或模型。`mechanism` 仅借鉴「尺寸有来源、对不上的规格不渲染」的纪律。Sketchfab DroneCore 2 Exploded 为 CC BY-ND，禁止改作且不纳入实现。上述参考均不是 DJI Mini 5 Pro，本项目保持通用四旋翼。

## C. 构图与交互

- 在 1440×960、390×844 的深色和浅色生产截图中，主体整包不触底、不右裁；四周留白均 ≥8%，主体占画布高约 58–72%。
- 常驻标签桌面不超过 8、移动端不超过 3；标签之间无叠字，最小轮廓间距目标 16px，不压其他部件。必要标签在选中/悬停时兜底，不为达标隐藏选中项。
- 爆炸滑杆、重置视角、部件列表和材料入口在 390 视口内可访问；无页面横向溢出。
- 至少验证一个真实部件深链/选中态，云台或视觉组件优先；URL、详情、列表和三维高亮一致。
- WebGL 不可用时沿用通用 2D/分层回退；减少动态不引入持续自动运动。既有手机机位与渲染不得被无人机配置改变。

## D. 主线与静态包

- 可走通：首页商品入口 → 世界地图（无记录时说明缺口）→ 商品拆解 → 代表性路线/材料（按证据显示或待核验）→ 国家账本（无记录时说明缺口）。
- `scripts/build-drone.mjs` 离线、确定性地生成不可变 release 和审核记录；`scripts/build-qoder-preview.mjs` 能把无人机打入参赛静态包。
- 本阶段只做定向门禁、受影响回归和生产截图；全量回归留到夜间最终收尾。公开站与 Qoder 均不发布。

- 1440 / 390 深浅生产截图及默认态、选中态的关键量测。
- typecheck、lint、相关测试、生产构建和受影响回归数字。
- 独立提交号与 RECOVERY 顶部条目；阶段结束即停止并汇报。
