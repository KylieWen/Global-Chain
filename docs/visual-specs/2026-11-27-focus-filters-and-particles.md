# 选中国家的筛选菜单与粒子强度（批次 6）

日期：2026-11-27

## 筛选菜单

选定国家后，地图左下出现「筛选 X 的流向」面板（`.atlas-focus-filters`）。四组条件可组合：

- **流向**：全部 / 流入该国 / 流出该国（按申报国口径，流入=流向该国）
- **伙伴地区**：东亚、东南亚、南亚、中东、欧盟、欧洲其他、北美、拉美、非洲、大洋洲，可多选
- **贸易关系**：不限 / 顺差（对该伙伴流出 > 流入）/ 逆差
- **伙伴规模**：不限 / ≥1 亿 / ≥10 亿 / ≥100 亿美元（按对该伙伴的进出口合计）

面板头部实时显示「保留 X / Y」，「清除 N」一键复位；换国家自动重置。实现：`lib/trade-focus-filters.ts`（M49→地区表、伙伴进出口合计、过滤）+ `components/map-focus-filters.tsx`（UI）。实测中国 + 2025 + 手机：67 条 → 仅流出 40 条 → 再限欧盟 12 条。

## 粒子强度与方向

- 粒子预算权重由 √factor 改为 factor^1.6（`lib/flow-encoding.ts`），大流量拿到的粒子数明显更多。
- 尾迹长度按 `0.5 + factor*0.9`（WebGL）/ `0.55 + factor*0.8`（Canvas2D）缩放，重流量形成长亮带，轻流量只剩细线。
- 单商品视图下粒子按方向分色：流出 `#8be4c4` 冷色、流入 `#d8bb84` 暖色；多商品对比仍按商品配色。
- 选定国家后在地图弧线中点标注前 5 大流向的金额（`atlas-flow-label`），沿弧线错位排布避免叠字。
