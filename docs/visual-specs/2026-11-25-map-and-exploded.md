# 页面级视觉规格试验（2026-11-25）

目的：验证“先写可执行视觉规格，再派执行模型”是否比“口头要求更好看”更稳定。本文件是**试验组**，对照组为已有截图 `output/qa/model-switch-2026-11-25/round-5-map/` 与 `round-7/`。完成后用同口径截图对比，由用户决定是否把此写法固化为流程。

原则：规格只约束呈现，不改数据、查询、契约与发布体系；参数落在现有 `flow-config.ts` 与 `content/exploded-appearance.json` 的可调范围内，新增外观参数仍需配置化，不写死在组件里。

## A. 世界地图 /map

### 布局（1440×960）
- 顶栏 64px；页面标题、视图切换、筛选条件合并为一行，高 56px。
- 地图画布占剩余高度，≥760px；图例与时间轴作为画布内底部浮层，不再额外占文档流高度，首屏必须同时看到地图、图例、时间轴。
- 画面重心：所选流向的包围盒居中，下方空海洋不超过画布高度 18%。

### 流向（对应 flow-config 参数）
- 桌面默认：density 1.0、speed 0.55、trail 0.62、glow 0.65、maxParticles 600；粒径 1.2–1.8 CSS px（比现在更小更密）。
- 束宽由金额 band 驱动，相邻 band 的视觉宽度比 ≥1.6，小额流仍可见（最小束宽不低于 3px 等效）。
- 同起点/终点的同向弧：稳定横向偏移，相邻弧间距 ≥14px，曲率方向交替，避免巴西→中国这类重叠。
- 节点：汇聚点外发光半径 10–14px，呼吸周期 2.4s、幅度 ≤15%，不闪烁。
- 入场：流向 600ms 淡入，无大规模飞入动画；减少动态偏好时静态束。

### 移动端（390）
- 默认取景覆盖所选全部流向的包围盒，不只对准最强一端。
- 画布高度 ≥52vh；时间轴独立一行置于画布下方，可拖可键盘。
- 性能：390 帧耗中位 ≤8ms；1440 ≤6ms；不达标时先降粒子上限再降辉光。

## B. 商品拆解爆炸图

### 相机与构图
- 透视 fov 35，默认 yaw −28°、pitch 18°。
- 默认爆炸程度 0.35 时，整机与全部展开层级完整入画，主体占画布高度 62–72%，四周留白 ≥8%，不得被视口底边裁断。

### 展开与形态
- 沿机身法线单轴展开；front/mid/rear 层距为机身厚度的 0.9 / 0.55 / 0.9 倍。
- 同层部件沿 X 轴错位，避免互相遮挡；零件片厚度 ≥0.06 倍机身厚度，圆角半径 0.02。
- 摄像头岛在默认视角可见，不被机身挡住。

### 标签
- 同时常驻标签 ≤6 个：当前层级与选中路径；其余 hover 或选中时出现。
- 标签置于投影轮廓外侧，引线 1px，任何两个标签不得叠字。

### 配色与层级
- front（屏幕/玻璃）冷色；mid（主板/电池/芯片）中性色加品牌强调；rear（结构件）暖灰；材料层按稀有金属/碳/铜/铝区分。
- 右侧层级列表保持整机→模块→装配体→零件→材料；数据缺层按实际渲染，不补假层。

### 交互与移动端
- 拖动旋转阻尼 0.08；滚轮缩放 0.7–2.2；双击复位；点部件联动右侧详情与既有深链。
- 390 下材料组改为底部横向滚动色带或并入层级列表，不得被画布右缘裁切。
