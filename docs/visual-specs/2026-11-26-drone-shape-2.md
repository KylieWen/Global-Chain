# 无人机外形与取景重做（批次 1）

日期：2026-11-26
范围：只重做无人机三维工作台的机体外形、镜头取景、标注意图与内部件可见性；沿用既有 16 节点 BOM、路由、数据版本与发布体系，不新增商品、不改数据。

## 触发原因

上一版（`bde9bec`）的机体在真实截图里被建成"宽钝前脸 + 窄尾"的圆角夹心板，云台是挂在机头前方的大方块，桨叶在常规机位几乎看不见，两枚深度 1 标签直接压在机身上。并排对照母版 `master-a-17.005s` 与 `master-a-4.7s`，形态差距不是细节问题，是朝向问题。

根因：机身平面形状的 v 轴经 `rotateX(-π/2)` 映射到 −z，`bodyPlan` 里把"鼻端窄"写到了最宽处，导致前脸被撑到最宽、尾部反而收窄。

## 本批改动

1. **机体剖面重写**（`apps/web/lib/drone-geometry.ts`）
   - `bodyPlan()` 显式定义：尾部最宽、鼻尖收窄，半宽 0.20 → 0.07；注释记下旧版反向映射的坑。
   - 机身拆成薄下壳 + 抬起的尾甲板 + 薄鼻梁，不再是叠起来的圆角板；前部加深色传感带与两只前视"眼"，尾部加散热口，四根短起落撑。
   - 按真机比例把机体放大一档（机长 0.59、机宽 0.40），桨叶半径 0.192，机身/轴距比从 0.38 收到 0.36 附近；先前的机型偏"机身小、机臂长"，放大后中央占比才对得上 Mini 级。
   - 机臂改为锥形圆管 + 小圆柱铰链；`r=0.042` 电机 + 金属顶盖；细双叶桨用 Shape 锥形叶片 + 迎角 `±0.13` + 黄色桨尖，四臂相位各异，低机位也能读出旋转面。
   - 云台拆成小吊舱（无镜头壳体）+ 独立镜头节点，支架为浅色板 + 立柱，不再是一体"炮筒"。
2. **爆炸位移收紧**（`apps/web/lib/drone-workspace-layout.ts`）
   - 机臂 spread 收到 0.36 / 0.28，爆炸态机臂抬到 y=0.17；遥控器簇收近到 x −0.56…−0.64。
   - 云台 bracket / pod / lens 收在鼻下并分散（pod `[0,-0.24,0.32]`、lens `[0,-0.24,0.44]`、axis `[±0.17,-0.2,0.28]`），镜头与核心板不再互相遮挡。
3. **镜头与取景**（`apps/web/components/drone-stage.tsx`）
   - 机位 YAW 0.66 / PITCH 0.44 / FOV 30；用屏幕空间迭代拟合（`FRAME_FILL` 0.80，爆炸 >0.3 时 0.87，3 次投影迭代）取代包围球拟合，整机在舞台里的占比可控。
   - 爆炸态随机位抬升 0.26 rad（上限 `MAX_PITCH`）：装配机位下两层壳体在屏幕里会压成两块"饼"，抬高后能看进夹层，部件分层才成立；用户手动旋转仍叠加在这之上。
   - `ACESFilmicToneMapping` + exposure 1.05，配合 `RoomEnvironment` + `PMREMGenerator` 程序化环境反射（intensity 0.45，失败静默兜底，不引外部 HDR），白色机身不再过曝成一片。
   - 灯光改为 key `1.55` / rim `0x6fc6de` `0.95` / fill；地面 `GROUND_Y=-0.145`、圆环 0.62/0.95/1.28/1.62、24 刻度、`GridHelper` 3.6、雾 4.2→12。
4. **标注**（同文件）
   - 根节点不再生成浮动标签；装配态标签从整机屏幕包围盒中心沿部件方向推到包络外，爆炸态贴自己部件包围盒外 6px，减少长引线。
   - 每帧碰撞避让（`LABEL_NUDGE=18`、`TRIES=5`），被遮挡则隐藏，选中/悬停例外；窄舞台（<640）只留深度 1 模块标签与选中项。
   - 内部板（board/esc/chip/sensor）在 `explosion<0.08` 且未选中/悬停时隐藏，消除穿模绿边。
5. **样式**（`apps/web/components/drone-workstation.css`）
   - 舞台背景加中心径向辉光与底部内阴影；≤640 滑杆改 grid（`span` nowrap + 输入占剩余），修掉"爆炸程度"换行。

## 结果与仍存差距

- 装配态：白色低趴机身、四条机臂、四个电机与双叶桨（黄尖）、鼻下小云台、两只前视传感眼；1440 与 390 均无横溢，标签落在机身外。
- 爆炸态：13 枚标签、1 处重叠（"视觉组件（下视/前后视/红外 TOF）"与"云台总成"）；机臂径向展开后仍有一条被主体遮住，"机臂组件"的引线偏长。
- 诚实边界：机体仍是程序化抽象，没有品牌 CAD 级前脸折线与面板分缝，不能宣称与母版视频"一模一样"；母版里没有遥控器节点，本站按 BOM 保留并放在侧后。
