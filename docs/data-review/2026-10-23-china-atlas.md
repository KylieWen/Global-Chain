# 中国供应链区域资料审核

审核批次：2026-10-22采集、2026-10-23本地验收。用户明确要求五个现有商品均提供中国地图，覆盖逐步补齐；本批不部署服务器。

## 数据范围

- 独立区域资料版本：`china-supply-geography-2026.10.1`；入口文件为`content/geography/china-supply-atlas-2026-10-22.json`。
- 五个商品共13个区域节点、8条代表性环节连接；手机2、棉T恤3、大豆油2、电动自行车3、空调3。
- 连接表达生产环节的阅读顺序。两端公开资料分别支持区域角色，不支持两企业之间的采购、客户或物流事实。所有连接金额为null、金额状态unknown，不伪造金额、份额或运输线路。
- 空调3个节点可继续进入既有企业与环节资料：宁波金田、佛山美芝、珠海格力。机构位置与工厂位置分开理解。

## 来源与提取

原始文件在`data/raw/china-atlas-2026-10-22/`，成功HTTP响应与精确UTC提取时间保存在相邻`.meta.json`中；早于meta归档的全国底图以原始文件修改时间记录获取时间。所有实际使用来源的URL、发布机构、适用范围、原始路径和SHA-256均进入区域资料包。

- 地图：阿里云DataV.GeoAtlas全国省级边界及六份省级下属城市数据。原始35个要素全部保留，其中34个具名省级要素与南海诸岛/边界参考要素；未移除港澳台或南海相关要素。
- 手机：深圳市发展改革部门的2022智能终端产业资料；郑州市政府2025富士康智能终端生产基地资料。郑州页面实际发布日期经原始HTML核实为2025-02-28，未使用最初误判的2024年。
- 棉T恤：新疆政府2025棉纺产业资料、柯桥政府2024纺织产业资料、番禺政府2024服装产业资料。后两者涵盖纺织/服装大类，不称为某件T恤的确切生产地。
- 大豆油：黑河政府2025大豆种植资料、九三食品哈尔滨加工能力官网资料。原料种植与加工节点之间只作代表性区域联系，不认定九三的具体采购地。
- 电动自行车：天津工信部门2026产业活动、锡山政府2026电动车产业资料、天能公司历史业务简介与长兴联系页。锡山来源包含电动两轮车大类；天能来源不证明特定整车客户。
- 空调：金田官方铜管业务、GMCC佛山联系地址、格力珠海公司概况；已有产品能力与企业入口继续解析既有不可变产业网络。

未能直接获取的原绍兴URL已替换为实际可访问的柯桥政府页面；未将404或挑战页面当作成功来源。天能首页本身不足以支持电动助力车和长兴位置，改用实际下载的公司简介与联系页，保留早期下载记录。

## 转换与验证

1. `scripts/fetch-china-atlas.ps1`按固定输入抓取公开快照，已有原始文件只读保留，不覆盖。
2. `scripts/build-china-atlas.mjs`从`china-atlas-input-2026-10-22.json`与原始文件重建区域资料。城市点采用DataV的城市参考中心，四舍五入到0.01度，明确标为`approximate_city_anchor`，不称为厂址。省级底图不进行坐标删减。
3. 浏览器只在渲染副本上规范d3环绕方向；不修改原始地图。客户端无地理或产业实时请求。
4. `RegionalAtlasSchema`校验期间、单位、方法、版本、状态、来源、坐标范围、引用、重复ID和连接两端商品一致性。领域查询负责省份与环节筛选；空白区域显示未收录反馈。
5. `tests/china-regional-atlas.test.ts`核对五商品覆盖、原始文件哈希、省级要素、筛选与邻接、空白区域和错误引用拒绝。

本批没有修改五个商品的published fixture、海关观察、既有release或active manifest；新的区域整理有独立版本，不能冒充历史商品版本同期的区域观察。原资料年份在节点详情保留，整个区域包的整理日期不替代来源年份。
