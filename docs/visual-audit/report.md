## 2. 两条2023年统计复核

本轮没有修改任何已有不可变release。当前激活版本为 `globe-chain-smartphone-2026.1`，120/122条统计已更新至2024或2025年。

- 刚果（金）含黄金官方储备：World Bank `FI.RES.TOTL.CD` 查询2023—2026，2024和2025返回空值，2023有值。
- 刚果（金）对华钴出口：UN Comtrade按报告国180、伙伴156、HS 8105、出口方向查询2024和2025，两次均无匹配记录。

因此保留两条2023年原值。这表示所查官方接口没有返回同口径更新，并未用其他口径的数据代填。HTTP状态、查询地址和完整返回见 [官方复核记录](data-recheck.json)。历史供应链内容的2023期间属于另一数据层，仍按实际期间呈现。
