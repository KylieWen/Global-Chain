## 2. 官方来源与核验

- 宏观数据：[世界银行WDI](https://api.worldbank.org/v2/country/AUS;COD;CHL;CHN;DEU;IDN;JPN;KOR;USA/indicator/TX.VAL.MRCH.CD.WT?date=2024:2025&format=json&per_page=100)，指标为商品出口、商品进口和官方储备。按国家及指标选择最新非空值，贸易差额只用同年输入。
- 海关数据：[UN Comtrade](https://comtradeapi.un.org/)，逐一核对报告方、伙伴、方向、商品分类H6、期间和统计口径；中国多项2025查询为空，采用2024实际响应。空响应不解释为0。842继续保留来源统计区域含义，未替换成ISO/M49 840。
- 数量单位：[UN Comtrade官方单位表](https://uncomtrade.org/docs/supplementary-quantity-units/)，5为件数，8为kg；缺失或未识别单位不补默认值。
- 美国：[USITC HTS 8517.13](https://hts.usitc.gov/reststop/search?keyword=8517.13)：第一栏一般基础关税Free，第二栏35%。新版展示第一栏基础0%，明确排除未核验的Chapter 99、原产地附加税和其他费用，不表示总税负0。
- 德国：[德国海关官方商品税率表](https://www.zoll.de/SharedDocs/Boxen/DE/Fragen/0082_beispiele_zollsaetze.html)：手机基础关税0%，标准进口增值税19%；特殊措施、免税与税基另依实际条件。
- 中国：[2026进出口税则公告及附件](https://gss.mof.gov.cn/gzdt/zhengcefabu/202512/t20251231_3981044.htm)：PDF第1238页、印刷第1228页，8517.1300智能手机最惠国0%、普通20%；完整出口税表102项未列该商品，按该表无出口关税。这不确定退税率或退税资格，也不覆盖原产地附加措施。对应页已渲染并目视核对列位置。
- 中国：[增值税法](https://shanghai.chinatax.gov.cn/sjtax/ztzl/yshj/ldjj/202412/t474700.html)：第十条、第十四条、第三十八条支持2026年施行的标准进口13%及组成计税价格，具体优惠另核。
- 类别资料采用Apple、Samsung、Samsung Display、Qualcomm、Henkel、Heraeus、TSMC官方资料，具体绑定见 `content/refresh-2026-09-16.json`。TSMC年报使用网页读取结果；Samsung Electro-Mechanics相机资料全文读取超时，只核对了官方域名检索摘要，已在来源记录明示，不宣称全文下载成功。

## 4. 仍未解决的缺口

不能宣称“所有已发布接口均已知”，也不能宣称“全部同步到当前年”。本轮仍保留以下明确限制：

1. 刚果（金）官方储备：WDI所查2024/2025年没有非空值，保留2023年原指标及来源。没有用其他口径或新闻中的外汇数字替代含黄金官方储备。
2. 刚果（金）对华钴出口：所查2024/2025年无匹配记录，保留原2023年观察；没有拿中国镜像进口冒充刚果（金）出口。
3. 智利2025手机出口、印度尼西亚2025手机进口：金额已更新，但来源数量单位为-1，数量仍为空；没有把缺失值设为零。
4. 美国其他税费仍未计算：依赖原产地、申报日期、Chapter 99、具体费用和其他条件。
5. 代表性路线的真实货量、批次去向、具体厂商客户关系，仍缺直接公开证据。13条示意连线没有改成实测物流。42条历史证据缺口未伪造关闭。
6. 14条生产活动、历史国家角色和制造工艺内容未在本轮全面重新核验，保留原2023期间；其中8条生产活动仍为unknown。组件类别核验不等于国别角色或供货关系核验。
7. 手续耗时、许可证适用条件、完整法律依据等没有全面补齐；没有用一个固定天数或“已审查”标签替代实质审查。税率核验不能使整个指南自动成为完整覆盖。
8. 用户未提供具体原产地、贸易模式、规格、交易日，无法形成一套适用于所有交易的确定税负或准入结论。

## 5. 发布与复现

旧 `globe-chain-smartphone-2023.16` 及所有既有不可变release保留。新增2026.1版本后，通过项目既有激活入口切换两个manifest；没有改Git远程、没有commit、没有push，也没有线上部署。

本轮固定批次复现：在仓库根目录运行 `node scripts/fetch-recent-sources.mjs`（已有快照复用，不覆盖），然后 `node scripts/build-recent-release.mjs`，再执行候选测试。构建依赖已核验的 `content/refresh-2026-09-16.json`；prepare脚本是本批次整理工具，不是重新审查所有政策的自动化程序。

`node scripts/publish-recent-release.mjs` 用排他写入创建发布文件；已存在且字节不同会拒绝。发布前必须通过候选测试。日后刷新应新增批次与版本，不得重写已发布2026.1。可使用现有release rollback入口恢复旧版。
