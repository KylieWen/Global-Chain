# ADR 0003：本地世界国家轮廓地图

## 决策

世界地图使用 `world-atlas@2.0.2` 中基于 Natural Earth 1:110m 数据生成的国家 TopoJSON，并通过 `d3-geo@3.1.1` 的 Equal Earth 等积投影绘制为 SVG。

国家行政区轮廓是地图的主要可交互对象。只有当前 published 数据集中存在的国家可以点击并高亮；贸易观察作为独立覆盖层，以国家几何质心节点和连线显示。

## 原因

- 国家不能被单个散点替代。
- Equal Earth 投影保持全球面积比例关系，适合世界范围比较。
- 本地静态几何数据不依赖运行时地图 API、令牌或网络连接。
- SVG 国家路径可以提供键盘访问、整体点击、高亮、缩放和平移。

## 数据来源与许可证

- 几何来源：Natural Earth Admin 0 Countries，1:110m。
- 分发包：`world-atlas@2.0.2`。
- Natural Earth 数据为 public domain。
- TopoJSON 转换与客户端读取使用 `topojson-client@3.1.0`。

## 限制

- 1:110m 适合全球概览，不适合精确边界测量、领土争议判断或市县级定位。
- 地图不表示港口、矿山、工厂或具体物流线路。
- 国家质心连线只表达已发布的具体伙伴贸易观察，不证明材料进入某部手机。
- `partnerCode=0` 世界总计不会被绘制成双边连线。
