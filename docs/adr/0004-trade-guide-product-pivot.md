# ADR 0004：收敛为进出口贸易信息查询与指南针

## 状态

已接受（2026-08-30）

## 背景

项目评审指出，尝试做双边贸易交易、供应商撮合或类似交易市场会直接进入成熟平台已经覆盖的竞争领域，也会带来报价、履约、资质审核和实时库存等超出个人项目能力范围的复杂度。评审建议把 GlobeChain 定位为帮助商家和调研人员查资料的“一站式进出口贸易信息网站”。

## 决策

GlobeChain 的主产品定义为：

> 面向跨境采购和外贸调研人员的进出口贸易信息查询与指南针网站。

主入口围绕三个选择组织：

```text
商品 + 国家/地区 + 进口/出口方向
              ↓
      关税核验 / 手续 / 文件 / 官方入口
```

其中：

- 进口查询中的国家/地区表示进口目的地或适用管辖区。
- 出口查询中的国家/地区表示出口起运地或适用管辖区。
- 指南内容是静态、部分覆盖、人工审核的研究起点；税率、许可和产品要求必须按当前日期、原产地、具体规格和官方系统重新核验。
- 供应商、制造工艺、材料贸易、国家账本和世界地图继续保留，但作为理解商品和政策背景的辅助模块，不是交易撮合、报价或订单系统。
- 不在运行时接入 AI/LLM、外部政策 API 或数据库；后续若使用 AI，只能考虑离线资料整理辅助，并须经过人工审核后进入 published 内容。

## 目标用户

### 首要用户：跨境采购人员

他们需要快速确认商品归类、目的地规则、可能的税费核验入口、资料清单和办理顺序，以便形成采购前的核验清单。

### 首要用户：外贸调研人员

他们需要把国家政策、商品背景、供应链角色和贸易统计放在同一条可引用的研究路径中，并能够回到官方来源核查。

学生、教师、记者和公众是重要的次级用户，但不替代首要用户的任务导向。

## 为什么保留供应链模块

供应链是 GlobeChain 的差异化背景能力：它解释商品从材料到成品的生产阶段，以及国家在其中可能扮演的角色。它不能被删除，因为它帮助用户理解为什么某项政策、原产地或产品合规要求会出现；但页面必须明确“代表性路线不等于某一批货物的唯一真实路线”。

## 数据与合规边界

- `TradeGuide`、`TariffMeasure`、`TradeRequirement`、`TradeProcedure`、`TradeDocumentRequirement` 和 `PolicyDocument` 组成独立的贸易指南层。
- 每条政策资料带期间、来源、证据、method、数据集版本、内容版本和覆盖状态。
- `unknown`、`withheld`、`estimated` 与来源明确报告的真实零值必须分开；未知税率显示“待核验”，不能显示为 0%。
- 指南不是法律意见、报关代理服务、税额承诺或合规认证。
- 官方门户只作为核验入口；页面不复制受限制的法律文本，也不承诺完整覆盖所有产品、州/成员国规则或贸易救济措施。

## 被否决的方向

- **双边贸易交易平台**：需要交易撮合、供应商资质、库存、报价、支付和履约能力，且没有相对成熟平台的优势。
- **实时政策 API/运行时 AI 问答**：会引入版本、责任、延迟、许可和错误解释风险，不适合当前个人项目的可验证边界。
- **先扩大全球商品覆盖**：在核心查询流程和政策内容模型稳定前，继续只深度维护通用智能手机。

## 验收标准

1. 用户可从首页进入贸易指南，选择商品、国家/地区和方向。
2. 结果页至少展示关税核验、手续、文件、办理步骤、官方入口、最近复核时间和覆盖限制。
3. 无结果或未知税率不会被渲染为“没有规则”或 0%。
4. 用户可以从商品背景跳回贸易指南，也可以继续查看供应链、国家账本和来源版本。
5. 页面和导出不把指南、供应链示意或海关贸易额解释成交易撮合、企业利润或单件商品成本。
