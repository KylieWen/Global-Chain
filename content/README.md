# GlobeChain 内容配置

本目录保存经过审核、由 schema 和构建脚本读取的人工内容配置。它与官方贸易统计原始快照分开维护。当前主产品是面向跨境采购和外贸调研的进出口贸易信息查询指南；供应链路线和工艺内容是辅助背景。

- `routes/`：代表性供应链路线、节点、连接、生产活动、步骤、内容版本、整理方法和局限。
- `trade-guides/`：按商品、国家/地区和进口/出口方向整理的静态关税核验、手续、文件、办理步骤和官方入口。
- 内容记录必须逐条引用来源和 evidence，并明确证据只支持国家角色、直接双边流向，还是代表性策展连接。
- 贸易指南必须保留覆盖状态、最近复核时间、官方来源和限制；未知税率不得填充默认值。
- 页面不直接读取本目录；构建脚本将审核后的内容与统计快照组合为 `data/published` fixture。
- 修改内容配置后应重新运行对应的确定性构建和全部质量检查，不得直接手工改写发布结果作为唯一流程。
